2.1 向量代数与空间解析几何 GEOMETRY

🗣 先说人话：平面是一张无限大的纸，法向量是垂直插在纸上的箭头

只要知道平面过哪个点、法向量朝哪，这张「纸」就唯一确定了。直线则像一个点沿着一个方向无限延伸。空间几何题，本质就是找点和方向。

平面与直线

平面点法式：A(x−x₀) + B(y−y₀) + C(z−z₀) = 0；直线对称式：(x−x₀)/l = (y−y₀)/m = (z−z₀)/n。

距离与夹角

点到平面距离 = |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²)。线线角看方向向量，线面角看方向向量与法向量。

必须会写 平面点法式：A(x−x₀) + B(y−y₀) + C(z−z₀) = 0
点到平面距离：d = |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²) 写平面方程前，先确认法向量；写直线前，先确认方向向量与一个已知点。

例：求过点 (1, 0, 0) 且法向量为 (1, 1, 1) 的平面方程。

代入点法式：1(x − 1) + 1(y − 0) + 1(z − 0) = 0，整理得 x + y + z = 1。

2.2 多元函数微分学 PARTIAL DERIVATIVES

🗣 先说人话：偏导是「固定其他人，只看一个人怎么变」

山顶的气温同时受海拔和纬度影响。偏导就是「纬度不动，只往东走一步，温度变多少」。梯度则告诉你：往哪个方向走，温度上升最快。

考点核心动作易错点
全微分dz = f_x dx + f_y dy偏导存在推不出可微
复合函数画变量依赖图，链式相乘再相加漏项、漏乘内层导数
隐函数两边对 x 求导，把 y 看成 y(x)忘记 y′ 项
方向导数 / 梯度∂f/∂l = grad f · e_l方向向量未单位化
条件极值拉格朗日乘数法忘记比较边界与约束
梯度与方向导数 grad f = (f_x, f_y, f_z)；∂f/∂l = grad f · e_l，其中 e_l 是单位方向向量 梯度方向是函数增长最快的方向，梯度的模就是最大方向导数。

例：设 z = x²y，求 ∂z/∂x 在点 (1, 2) 处的值。

∂z/∂x = 2xy，代入 (1, 2) 得 4。偏导就是把 y 当常数。

2.3 多元函数积分学 MULTIPLE INTEGRALS

🗣 先说人话：二重积分是「把平面切成小格累加」，曲面积分是「把曲面切成小片累加」

二重积分算平面区域上的总量，三重积分算立体里的总量，曲线/曲面积分算沿路径或曲面分布的量。三大公式（格林、高斯、斯托克斯）的作用，是把「边界上的积分」换成「内部区域的积分」，或者反过来。

二重 / 三重积分

直角坐标定限、极坐标（dσ = r dr dθ）、柱面坐标、球面坐标；对称性优先，能利用奇偶性就别硬算。

曲线 / 曲面积分

第一类看弧长/面积，第二类看方向；格林公式处理平面闭曲线，高斯处理闭曲面，斯托克斯处理空间闭曲线。

三大公式 格林：∮_L P dx + Q dy = ∬_D (Q_x − P_y) dxdy
高斯：∯_Σ P dydz + Q dzdx + R dxdy = ∭_Ω (P_x + Q_y + R_z) dv
斯托克斯：∮_Γ P dx + Q dy + R dz = ∬_Σ (rot F · n) dS 用公式前先看：闭不闭合？方向对不对？不闭合时能不能补面/补线？

例：设 D 为单位圆 x² + y² ≤ 1，求 ∬_D (x² + y²) dσ。

极坐标：∫₀^{2π}∫₀¹ r² · r dr dθ = 2π · 1/4 = π/2。最容易错的地方是漏掉雅可比 r。

📌 数一提醒

多元积分是数一最大分值板块，也是解答题常客。先判断「区域是否封闭、是否适合换面、是否适合极坐标/球坐标」，再动笔。不要一上来就硬算。

2.4 无穷级数 SERIES

🗣 先说人话：级数是「无限个数相加」，收敛是「加得完」

1/2 + 1/4 + 1/8 + … 越加越接近 1，叫收敛；1 + 1/2 + 1/3 + … 越加越大，叫发散。幂级数则是「带 x 的级数」，不同的 x 可能收敛也可能发散，收敛范围就是收敛域。

题型方法注意
正项级数判敛比较、比值、根值、积分先看通项是否趋于 0
交错级数莱布尼茨判别法单调递减 + 通项趋于 0
绝对 / 条件收敛先判绝对值级数绝对收敛 ⇒ 收敛
幂级数收敛域先求收敛半径，再单独判端点端点最容易漏
和函数凑标准展开式，逐项求导/积分求导后端点敛散性可能变
傅里叶级数套系数公式，写和函数数一独有，注意狄利克雷定理
三个必须记住的展开式 1/(1−x) = Σxⁿ（|x| < 1）；eˣ = Σxⁿ/n!；ln(1+x) = Σ(−1)ⁿ⁻¹xⁿ/n（−1 < x ≤ 1） 求和函数先「凑」这三个标准式，再逐项求导或积分。

例：求幂级数 Σ xⁿ/n 的收敛域。

由比值法得收敛半径 R = 1，因此在 (−1, 1) 内绝对收敛。
x = 1 时为调和级数 Σ1/n，发散。
x = −1 时为交错调和级数，收敛。所以收敛域是 [−1, 1)。

2.5 常微分方程 DIFFERENTIAL EQUATIONS

🗣 先说人话：微分方程是「知道变化率，反求函数」

如果知道一辆车的速度随时间怎么变，能不能反推出它任意时刻的位置？这就是微分方程。解不是数，而是函数；通解带常数，特解由初始条件确定。

一阶方程

可分离变量、齐次、一阶线性、伯努利、全微分方程。先分类，再套对应解法。

高阶方程

可降阶、二阶常系数齐次/非齐次、欧拉方程。非齐次特解形式看自由项与特征根是否重合。

一阶线性方程通解 y′ + P(x)y = Q(x) → y = e^(−∫Pdx) (∫Q·e^(∫Pdx)dx + C) 先化成标准形，再找积分因子 e^(∫Pdx)。

例：求 y′ + y = e⁻ˣ，y(0) = 1 的解。

积分因子 eˣ，两边相乘得 (y eˣ)′ = 1。
积分得 y eˣ = x + C。
代入 y(0) = 1 得 C = 1，所以 y = (x + 1)e⁻ˣ。
⚠️ 数一独有：欧拉方程

x²y″ + pxy′ + qy = 0，令 x = eᵗ 化为常系数方程。代换后注意链式求导，别把 y′ 直接当成 dy/dt。

⚠️ 本章避坑清单 PITFALLS

多元积分与级数，错一次记一次
  • 极坐标漏乘雅可比 r；球坐标漏乘 r² sin φ。
  • 第二类曲线/曲面积分方向取反，整题符号全错。
  • 高斯公式忘记补面，或补面后忘记减去补面上的积分。
  • 幂级数收敛域只写开区间，忘了单独判两个端点。
  • 傅里叶系数公式与和函数表达式混淆。
  • 微分方程非齐次特解形式，没检查自由项与特征根是否重合。
