1.1 极限与连续 LIMITS

🗣 先说人话：极限是「无限靠近」

倒车入库时，车可以无限接近库线，但不一定压线。数学里的极限也一样：只关心靠近的过程，不关心终点是否到达。sin x / x 在 x = 0 处没有定义，但 x 越靠近 0，函数值越靠近 1，所以极限是 1。

必须认全的七种未定式

类型常见形式首选方法
0/0sin x / x等价无穷小、洛必达、泰勒
∞/∞ln x / x洛必达、抓大头
0·∞x ln x改写为 0/(1/x) 或 ∞/(1/x)
∞−∞1/x − 1/sin x通分、有理化、泰勒
1^∞(1+x)^(1/x)取对数或凑 e 的极限
0⁰ / ∞⁰x^x取对数化为 0·∞
等价无穷小（x → 0） sin x ~ tan x ~ arcsin x ~ arctan x ~ ln(1+x) ~ eˣ − 1 ~ x
1 − cos x ~ x²/2；(1+x)^α − 1 ~ αx；x − sin x ~ x³/6；tan x − x ~ x³/3 只允许在乘除因子中替换；加减法里直接替换是最高频的错误。
两个重要极限 lim(x→0) sin x / x = 1；   lim(x→∞) (1 + 1/x)ˣ = e 1^∞ 型统一处理：lim u^v = e^(lim v·ln u)，或凑 (1 + 1/t)^t。

例题：一道题串起三种工具

求 lim(x→0) (tan x − sin x) / x³。

先化简结构。tan x − sin x = tan x(1 − cos x)，把差变成乘积。
再等价替换。tan x ~ x，1 − cos x ~ x²/2，所以分子 ~ x³/2。
约分。(x³/2) / x³ = 1/2，极限为 1/2。

如果直接对原式用洛必达，会越求越乱。先看结构，永远比直接求导快。

⚠️ 三个高频坑
  • 加减法中滥用等价无穷小：sin x − x 不能直接换成 x − x = 0。
  • 洛必达前不验证类型：不是 0/0 或 ∞/∞ 就用，结论无效。
  • 分段点只算一侧极限：左右极限都存在且相等，才叫极限存在。

1.2 一元函数微分学 DERIVATIVES

🗣 先说人话：导数是「仪表盘上的瞬时速度」

平均速度是「一段时间走了多远」，瞬时速度是「此刻仪表盘显示多少」。导数就是把平均变化率的 Δx 压到 0，得到某一瞬间的变化率。可导一定连续，连续不一定可导（比如 |x| 在 0 处）。

核心考点清单

求导与高阶导数

复合函数链式法则、隐函数求导、参数方程求导、对数求导法、莱布尼茨公式。重点不是背公式，而是识别结构。

中值定理

罗尔、拉格朗日、柯西、泰勒。证明题先看结论，再逆推辅助函数；看到「存在 ξ」先想中值定理，看到「二阶导」先想泰勒。

函数性态

单调区间、极值、凹凸性、拐点、渐近线、曲率。列表讨论最稳：定义域 → 导数 → 驻点/不可导点 → 符号变化。

数一专属

曲率 K = |y″| / (1 + y′²)^(3/2)，曲率半径 R = 1/K。偶有选择或填空，公式记住即可。

例题：极值 + 渐近线一次做完

求 y = x e⁻ˣ 的单调区间、极值与渐近线。

y′ = e⁻ˣ − x e⁻ˣ = (1 − x)e⁻ˣ，令 y′ = 0 得 x = 1。
x < 1 时 y′ > 0，函数递增；x > 1 时 y′ < 0，函数递减，所以 x = 1 是极大值点，极大值 y(1) = 1/e。
x → +∞ 时 y → 0，得水平渐近线 y = 0；x → −∞ 时 y → −∞，没有垂直渐近线。
📌 数一提醒

中值定理证明题是解答题常客。看到「f(a) = f(b)」想罗尔；看到「f(b) − f(a)」想拉格朗日；看到两个函数比值想柯西；看到「二阶导」想泰勒展开到二阶。

1.3 一元函数积分学 INTEGRALS

🗣 先说人话：积分是「把无数薄片加起来」

定积分不是一堆符号，而是把曲线下的面积切成无数薄片再累加。不定积分是「找谁求导能得到它」，所以积分和求导是互逆的。变限积分则是「一边切、一边累加」的函数。

三条主线

主线核心动作常见题型
不定积分凑微分 → 换元 → 分部 → 有理函数求原函数、递推公式
定积分性质、对称性、华里士、变限求导定积分计算、比较大小
应用面积、体积、弧长、物理量旋转体体积、曲线弧长
变限积分求导 d/dx ∫φ(x)^ψ(x) f(t) dt = f(ψ(x))ψ′(x) − f(φ(x))φ′(x) 上下限都是函数时，两项都要乘内层导数；这是选填高频陷阱。

例题：分部积分 + 反常端点

求 ∫₀¹ x ln x dx。

取 u = ln x，dv = x dx，则 du = dx/x，v = x²/2。
原式 = [x²/2 · ln x]₀¹ − ∫₀¹ x/2 dx。
x → 0⁺ 时 x² ln x → 0，所以第一项为 0；第二项 = 1/4，最终结果为 −1/4。

看到 ln x 与幂函数相乘，优先把 ln x 放进 u；看到 x 与 eˣ 相乘，优先把 eˣ 放进 dv。

⚠️ 积分三大坑
  • 换元后忘记修改积分上下限，或者忘记把 dx 换成 du。
  • 变限积分求导漏乘内层导数，尤其是上限为 x² 的情形。
  • 反常积分直接套牛顿—莱布尼茨，没先判断敛散性。

⚠️ 本章避坑清单 PITFALLS

做完题对一遍，能少丢 10 分
  • 极限先看类型，再选方法；不要一上来就洛必达。
  • 等价无穷小只换乘除因子，加减法先通分或泰勒。
  • 分段函数在分段点必须分别算左右极限、左右导数。
  • 中值定理证明题，辅助函数是从结论逆推出来的，不是硬凑。
  • 积分换元三件事：换被积函数、换 dx、换上下限。
  • 算完定积分养成检查符号与量纲的习惯。
