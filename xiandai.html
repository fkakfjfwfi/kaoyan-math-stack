3.1 行列式 DETERMINANT

🗣 先说人话：行列式是「面积 / 体积的缩放倍数」

一个 2×2 矩阵把单位正方形变成平行四边形，行列式就是新面积与原来面积的比。行列式为 0，说明平面被压扁成一条线，矩阵不可逆。

三条主线

性质化简 → 按行（列）展开 → 特殊结构（范德蒙德、爪型、三对角、加边）。先看结构，不要上来硬展开。

必背性质

|AB| = |A||B|；|kA| = kⁿ|A|；|Aᵀ| = |A|；|A*| = |A|ⁿ⁻¹。注意 n 是阶数。

二阶与三阶 |a b; c d| = ad − bc
三阶可用对角线法则，但更稳的是按行展开：|A| = Σ aᵢⱼ Aᵢⱼ，Aᵢⱼ 是代数余子式 代数余子式自带符号 (−1)^(i+j)，这是高频错点。

3.2 矩阵 MATRIX

🗣 先说人话：矩阵是「线性变换的说明书」

把向量喂给矩阵，它会把向量拉伸、旋转、剪切、投影。逆矩阵是「倒带」，秩是「变换后还剩几维有效信息」，伴随矩阵则是求逆时用的工具箱。

考点核心结论易错点
逆矩阵A⁻¹ = A*/|A|，A 可逆 ⇔ |A| ≠ 0(AB)⁻¹ = B⁻¹A⁻¹ 顺序写反
伴随矩阵AA* = A*A = |A|E；|A*| = |A|ⁿ⁻¹r(A*) 的三种情形记混
秩r(AB) ≤ min{r(A), r(B)}；r(A+B) ≤ r(A)+r(B)初等变换不改变秩
初等变换求秩、求逆、解方程组换行变号，倍乘改变行列式
分块矩阵对角块、三角块分别处理分块乘法顺序不能乱
伴随矩阵的秩 r(A*) = n（r(A) = n）；1（r(A) = n − 1）；0（r(A) < n − 1） 选择题常客，三种情形必须条件反射。

3.3 向量 VECTORS

🗣 先说人话：线性相关 = 「有人是别人的组合」

一组向量里，如果某个向量能由其他向量拼出来，这组向量就是线性相关的，说明信息有冗余。极大无关组就是「去掉所有冗余后剩下的最小队伍」，队伍人数就是秩。

判定套路

把向量按列拼成矩阵 → 做初等行变换 → 数非零行。相关 ⇔ 齐次方程组有非零解 ⇔ 秩小于向量个数。

正交化

施密特正交化：β₂ = α₂ − (α₂,β₁)/(β₁,β₁)·β₁；β₃ 再减去在两个方向上的投影。最后记得单位化。

相关性判定 α₁,…,αₛ 线性相关 ⇔ 存在不全为零的 kᵢ，使 Σkᵢαᵢ = 0 ⇔ r(α₁,…,αₛ) < s 「不全为零」四个字不能漏；全是零永远成立，没有意义。

3.4 线性方程组 LINEAR SYSTEMS

🗣 先说人话：解方程组就是「找所有满足约束的点」

齐次方程组的解构成一个过原点的空间，维数是 n − r(A)；非齐次方程组的解是这个空间平移一个特解。基础解系就是「这个空间的一组基」。

解的判定 Ax = 0 有非零解 ⇔ r(A) < n；基础解系含 n − r(A) 个向量
Ax = b 有解 ⇔ r(A) = r(A|b)；通解 = 特解 + 齐次通解 含参数方程组，先化简再按秩分类讨论，别一上来就克拉默。

例：求齐次方程组 x₁ + x₂ + x₃ = 0，x₁ − x₂ = 0 的基础解系。

系数矩阵 [[1,1,1],[1,−1,0]]，秩为 2，未知数 3 个，所以基础解系含 1 个向量。
由 x₁ = x₂，代入第一式得 2x₁ + x₃ = 0，即 x₃ = −2x₁。
取 x₁ = 1，得基础解系 (1, 1, −2)ᵀ，通解为 k(1, 1, −2)ᵀ。

3.5 特征值与特征向量 EIGENVALUES

🗣 先说人话：特征向量是「被矩阵作用后方向不变的向量」

大多数向量被矩阵一作用，方向就偏了；但总有那么几个特殊方向，只被拉伸或压缩，方向不变。这些方向就是特征向量，拉伸倍数就是特征值。

必背性质

Σλᵢ = tr(A)，Πλᵢ = |A|；Aᵏ、f(A)、A⁻¹、A* 的特征值可由 λ 直接推出。

对角化

A 可相似对角化 ⇔ A 有 n 个线性无关的特征向量。实对称矩阵一定可以正交对角化。

特征方程 |λE − A| = 0；对每个 λ，解 (λE − A)x = 0 得特征向量 重根时，几何重数（无关特征向量个数）小于代数重数，就不可对角化。

例：A = [[2,1],[1,2]]，求特征值与特征向量。

|λE − A| = (λ−2)² − 1 = (λ−1)(λ−3)，特征值为 1、3。
λ = 1 时解 (E−A)x = 0，得特征向量 (1, −1)ᵀ。
λ = 3 时解 (3E−A)x = 0，得特征向量 (1, 1)ᵀ。两个方向正交，正是实对称矩阵的性质。

3.6 二次型 QUADRATIC FORMS

🗣 先说人话：二次型是「带交叉项的曲面」

x² + 2xy + 2y² 这种式子，用矩阵写就是 xᵀAx。化标准形就是换一组坐标，把交叉项消掉，看清它到底是椭圆、双曲线还是抛物面。正定就是「除了原点，处处为正」。

正定判别 A 正定 ⇔ 顺序主子式全 > 0 ⇔ 特征值全 > 0 ⇔ 正惯性指数 = n 前提：A 是实对称矩阵。合同看正负惯性指数，相似看特征值。

例：判断 f = x² + 2xy + 2y² 是否正定。

二次型矩阵 A = [[1,1],[1,2]]，顺序主子式：1 > 0，1×2 − 1×1 = 1 > 0，所以 A 正定，f 正定。

⚠️ 本章避坑清单 PITFALLS

线代丢分，多半是这三个字：秩、方向、重数
  • |kA| 忘记 k 的 n 次幂；|A*| 与 |A| 的关系记混。
  • (AB)⁻¹ 顺序写反；(A+B)⁻¹ 直接拆成 A⁻¹ + B⁻¹。
  • 含参方程组不分类讨论，或漏掉系数为 0 的情形。
  • 基础解系向量个数算成 r(A)，应为 n − r(A)。
  • 特征向量忘记非零；重根时不做无关特征向量个数的判断。
  • 二次型正交变换时，特征向量顺序与特征值不匹配。
