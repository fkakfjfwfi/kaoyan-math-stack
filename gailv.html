4.1 随机事件与概率 EVENTS

🗣 先说人话：概率是「对不确定性的度量」

事件就是「可能发生也可能不发生的事」。互斥是「不能同时发生」，独立是「一个发生不影响另一个的概率」。这两个概念完全不同，是选择题最爱设的坑。

四个基本公式 加法：P(A∪B) = P(A) + P(B) − P(AB)
条件：P(A|B) = P(AB)/P(B)（P(B) > 0）
全概率：P(B) = ΣP(Aᵢ)P(B|Aᵢ)
贝叶斯：P(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ) / ΣP(Aⱼ)P(B|Aⱼ) 独立 ⇔ P(AB) = P(A)P(B)；互斥 ⇔ P(AB) = 0。两者不能混。

4.2 一维随机变量及其分布 ONE-DIMENSIONAL

🗣 先说人话：分布函数是「累积到这里的概率」

F(x) = P(X ≤ x)，像往杯子里倒水，倒到 x 位置时累计了多少。密度函数则是「每单位长度的概率浓度」，所以概率是密度曲线下的面积。

分布期望方差记忆点
0-1 分布pp(1−p)一次试验
二项 B(n,p)npnp(1−p)n 次独立重复
泊松 P(λ)λλ期望方差相等
均匀 U(a,b)(a+b)/2(b−a)²/12密度为常数
指数 E(λ)1/λ1/λ²参数在分母
正态 N(μ,σ²)μσ²标准化后查表
随机变量函数的分布 F_Y(y) = P(g(X) ≤ y)，先讨论 y 的范围，再解不等式 分布函数法是万能解法；密度法只适用于 g 单调的情形。

4.3 多维随机变量及其分布 MULTIVARIATE

🗣 先说人话：联合分布是「一张总表」，边缘分布是「只看其中一列/一行」

二维随机变量要同时看两个指标：身高与体重、两个零件的寿命。联合分布描述它们一起的规律，边缘分布只看其中一个，条件分布则是在已知一个取值的条件下看另一个。

必会三件事

由联合分布求边缘分布；判断独立性；求两个随机变量函数的分布（和、商、max、min）。

一个反直觉结论

边缘分布不能反推联合分布。两个变量各自正态，联合未必是二维正态；但联合正态时，不相关等价于独立。

独立性与卷积 X、Y 独立 ⇔ f(x,y) = f_X(x)f_Y(y)（连续型）
Z = X + Y 的密度：f_Z(z) = ∫ f(x, z−x) dx 二维题先画积分区域再定限，这是概率大题最稳的得分点。

4.4 随机变量的数字特征 EXPECTATION

🗣 先说人话：期望是「长期平均」，方差是「波动大小」

期望不是「一定会发生的结果」，而是重复很多次后的平均值。方差衡量结果离平均值有多散。协方差衡量两个变量是否同涨同跌，相关系数是它的标准化版本。

四条高频公式 E(aX + bY) = aEX + bEY
D(aX + b) = a²DX
D(X ± Y) = DX + DY ± 2Cov(X,Y)
Cov(X,Y) = E(XY) − EX·EY，ρ = Cov/(σ_X σ_Y) E(g(X)) ≠ g(E(X))；ρ = 0 只说明不相关，不一定独立（正态除外）。

4.5 大数定律与中心极限定理 LLN & CLT

🗣 先说人话：大数定律说「平均会稳」，中心极限定理说「平均会正态」

抛硬币次数越多，正面频率越接近 1/2，这是大数定律。而无论原分布是什么，样本均值经过标准化后都会趋近标准正态，这是中心极限定理。后者是统计推断的地基。

中心极限定理 X₁,…,Xₙ 独立同分布，E(X) = μ，D(X) = σ²，则 ΣXᵢ 近似服从 N(nμ, nσ²)
标准化：(ΣXᵢ − nμ) / (σ√n) → N(0,1) 除以的是 σ√n，不是 σn；这是最高频的计算错误。

4.6 数理统计的基本概念 STATISTICS

🗣 先说人话：统计量是「从样本里算出来的数」

总体是全部，样本是抽出来的一部分。样本均值、样本方差都是统计量。三大抽样分布（χ²、t、F）不是凭空来的，而是正态样本经过特定组合构造出来的。

三大分布与抽样分布 χ²：X₁,…,Xₙ ~ N(0,1) 独立 ⇒ ΣXᵢ² ~ χ²(n)
t：X ~ N(0,1)，Y ~ χ²(n)，独立 ⇒ X/√(Y/n) ~ t(n)
F：U ~ χ²(n₁)，V ~ χ²(n₂)，独立 ⇒ (U/n₁)/(V/n₂) ~ F(n₁,n₂)
正态总体：(n−1)S²/σ² ~ χ²(n−1)；(X̄ − μ)/(S/√n) ~ t(n−1) 样本方差分母是 n − 1；t 分布要求分子分母独立。

4.7 参数估计 ESTIMATION

🗣 先说人话：参数估计是「用样本猜总体」

总体里有个未知参数（比如合格率 p、平均寿命 μ），我们拿样本去猜它。矩估计用「样本矩 = 总体矩」，最大似然用「哪个参数最可能产生这组样本」。

矩估计：写出总体矩（如 E(X) = p），令它等于样本矩 X̄，解出参数。
最大似然：写似然函数 L(θ) = ∏f(xᵢ;θ)，取对数 ln L，对 θ 求导令零，解出 θ̂。
无偏性：检查 E(θ̂) 是否等于 θ；有效性比较方差，方差越小越有效。

4.8 假设检验 HYPOTHESIS TEST

🗣 先说人话：假设检验是「先假定无罪，再看证据够不够推翻」

原假设 H₀ 通常设成「没有差异 / 没有效果」，然后用样本算检验统计量。如果统计量落进拒绝域，就拒绝 H₀；否则只能说「没有足够证据拒绝」。

情形检验统计量分布
σ² 已知，检验 μU = (X̄ − μ₀)/(σ/√n)N(0,1)
σ² 未知，检验 μt = (X̄ − μ₀)/(S/√n)t(n−1)
检验 σ²χ² = (n−1)S²/σ₀²χ²(n−1)
📌 数一独有低频点

第一类错误概率就是 α（弃真），第二类错误概率是 β（取伪）。记住「均值已知方差用 U，方差未知用 t」，选择题基本够用。

⚠️ 本章避坑清单 PITFALLS

概率丢分，多半是「独立 / 互斥 / 不相关」搅在一起
  • 独立与互斥混淆：独立看 P(AB) = P(A)P(B)，互斥看 P(AB) = 0。
  • 边缘分布反推联合分布；联合分布才能决定独立性。
  • 二维积分区域画错，定限上下限写反。
  • D(X+Y) 忘记加 2Cov；独立时协方差才为 0。
  • 中心极限定理标准化时除以 σn 而不是 σ√n。
  • 最大似然忘记取对数，或漏掉参数空间边界。
